IPA de teste do meu jogo para iOS: HS e ESP Name até 150 metros, fonte pequena e sem linha de distância.

**Versão 3 de teste:** o HS agora aplica as trocas dos ossos quando os modelos base masculino e feminino são lidos pelo jogo. A rotina procura os nomes dos ossos, sem depender da ordem no arquivo. O ESP da V2 foi preservado.

[Abrir o IPA versão 3 para baixar](./meujogoHS-espname-iOS-v3.ipa)

O arquivo `meujogoHS-espname-iOS-v3.ipa` aparece na raiz deste repositório, ao lado deste README. Abra o arquivo e toque no botão de download (↓).

[Download alternativo pela Release](https://github.com/jrlescovar/meujogo-ios/releases/download/ios-hs-esp-1.28-teste3/meujogoHS-espname-iOS.ipa)

Para usar no iPhone:

1. Abra o link no Safari conectado à sua conta do GitHub.
2. Baixe o arquivo `.ipa` e abra Downloads no aplicativo Arquivos.
3. Importe o novo arquivo no ESign, assine e instale usando as mesmas opções da V2.

O usuário confirmou login e ESP funcionando no iPhone com a V2, mas o HS não teve efeito. Na V3 passaram 20 testes locais da rotina HS, 13 do ESP e 8 de integridade, com APIs simuladas. O efeito do HS na partida ainda precisa ser confirmado no iPhone.
